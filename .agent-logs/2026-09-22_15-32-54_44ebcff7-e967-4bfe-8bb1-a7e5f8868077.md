- **Gemini** for everything AI: `gemini-3.8-live` for the in-call voice agent, Flash for summaries/extraction, `gemini-embedding-001` for RAG vectors

## How the meeting room actually works

The browser connects straight to the Live API over a WebSocket. Our server never touches the audio — it only mints a short-lived ephemeral token (30-minute expiry, single use) so your Gemini key never reaches the client. That also sidesteps the fact that Vercel functions can't hold a long-lived socket open.

Live API gives us input *and* output transcription natively, which means the transcript arrives already split by speaker — you on one side, the agent on the other — with timings, rather than us running a separate speech-to-text pass.

Two limits I designed around, from the docs:

- Audio sessions cap at **15 minutes** and a single connection lasts about **10**. The server sends a `GoAway` warning first, so I'll enable context-window compression and session resumption to reconnect transparently mid-call. The user sees one continuous meeting.
- Audio+video is only ~2 minutes, so the agent is audio-only. Your camera still records to the video file; the agent just doesn't consume the video stream.

Meanwhile `MediaRecorder` captures the mixed stream locally and uploads to Blob on hangup, so playback afterwards is a real recording you can scrub against the real transcript.
